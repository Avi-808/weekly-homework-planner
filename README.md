# Weekwise Homework Planner

A simple weekly homework planner inspired by the supplied spreadsheet template.

## Features

- Plan homework from Monday through Sunday.
- Add assignments, subjects, estimated study time, due dates, priorities, and notes.
- See overdue and upcoming due dates at a glance, with a due soon count.
- Edit or remove assignments and mark tasks complete.
- See weekly progress, filter the task list, print the plan, or download a CSV report.
- Use subject colors to scan the planner quickly.
- Save plans in the current browser using local storage.

## Run it

Open `index.html` in a modern browser. No installation or account is required.

The planner starts with one generic example assignment. Your changes stay in the browser and device where you use it.

## Built with

HTML, CSS, and vanilla JavaScript.
